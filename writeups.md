1)How long did you spend working on the problem? What did you find to be the most difficult part?

I spent nearly 5 hours working on the problem. The most difficult part was setting up and configuring the React Native and Expo environment because my experience with React Native was at a basic level. I also faced challenges integrating the Yelp API and handling location permissions correctly. Through this project, I learned how to set up a mobile app, work with APIs, manage state, and improve the UI/UX of a React Native application.

2)What trade-offs did you make? What did you choose to spend time on, and what did you choose to ignore or do quickly for the sake of completing the project?

    spent most of my time working on location handling and integrating the Yelp API. Since I had limited experience with React Native, I used AI tools and documentation to understand how location permissions and GPS access work in mobile applications.For trade-offs, I focused more on making the core functionality work correctly, such as fetching nearby restaurants, pagination, favorites, and improving the UI. To complete the project on time, I kept some features simple, such as authentication, persistent storage for favorites, and advanced animations

3)If you finished with extra time, what improvements did you make that go above and beyond the requirements?

With the extra time, I improved the project beyond the core requirements by adding a dynamic search input field. Instead of only showing restaurants, users can search for different types of places such as cafes, sushi, pizza, or desserts using the Yelp API. I also improved the UI with polished cards, better buttons, and a favorites feature for saving liked restaurants.
